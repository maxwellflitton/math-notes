## The symmetry worth seeing
Each integration technique is a differentiation rule reversed:

| Differentiation | Integration |
|---|---|
| [[chain-rule]] | [[by-substitution]] |
| [[product rule]] | [[by-parts]] |
| $\frac{d}{dx}e^{ax} = ae^{ax}$ | [[exponents]] — hence the $\tfrac1a$ |
| the $\sin \to \cos \to -\sin$ cycle | [[trig]] — walk the cycle backwards |
